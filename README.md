# MahaUpdate 📰

**MahaUpdate** is a Maharashtra-focused news and current affairs portal built with Node.js and Express.

## Features

* News and current affairs
* Maharashtra-focused news coverage
* Responsive web interface
* Express.js backend
* RSS-based news integration (where configured)

## Technologies Used

* Node.js
* Express.js
* HTML
* CSS
* JavaScript

## Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/shivamtaware8-stack/maharashtra-news-portal.git
cd maharashtra-news-portal
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the application

```bash
npm start
```

Open your browser at:

http://localhost:3000

This project is intended to be deployed using a Node.js-compatible hosting platform. Additional configuration may be required for Vercel.

## Security

* Do not commit `.env` files or API keys.
* Keep credentials in environment variables.
* Do not commit `node_modules`.
